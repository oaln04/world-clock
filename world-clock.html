World Clock

Real-time clocks across timezones

About This Project

World Clock is a real-time application that displays the current time across multiple timezones with precision and elegance. It provides instant updates and a beautiful, responsive interface that works seamlessly across all screen sizes.

The application uses JavaScript's Intl API to handle timezone conversions and updates every second. Each timezone card displays the local time, date, and timezone offset, with visual indicators for day/night cycles.
