World Clock

Real-time clocks across timezones

A polished timezone dashboard built to match the main portfolio style, with day/night badges and live updates.

About This Project

World Clock brings multiple region clocks together in one responsive interface using JavaScript's Intl API. It refreshes every second and keeps the same visual identity as the rest of the site.

Each card clearly shows the city name, local date, exact time, timezone offset, and whether it's currently day or night there.
